# Atividade Prática: Algoritmo de Ordenação Shellsort

Esta atividade prática teve como objetivo o estudo, implementação e análise do Shellsort, um dos algoritmos de ordenação mais eficientes entre os de complexidade quadrática. O foco foi entender como a introdução do conceito de intervalos otimiza o método de ordenação por inserção tradicional(Insertion Sort), permitindo que elementos distantes sejam trocados de posição mais rapidamente.

#Conceitos aplicados e Funcionamento
Redução de Lacunas(Gap Sequence): O algoritmo começa comparando elementos separados por um grande intervalo. Conforme as iterações avançam, o intervalo diminui progressivamente até chegar a 1, momento em que o algoritmo se comporta como um insertion Sort tradicional.

Eficiência: Reduz o número de deslocamento de elementos longos, melhorando significativamente o desempenho em relação à inserção simples.

Estrutura de Dados: Manipulação de vetores/arrays e laços de repetição aninhados para controle de saltos e trocas.

#Tecnologias Utilizadas
Linguagem: Java
Conceitos: Algoritmos de Ordenação, Complexidade de Tempo e Manipulação de Arrays.
